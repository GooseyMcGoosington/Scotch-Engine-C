Scotch Engine, developed by me.

Features
Very Basic AI (WIP)
Depth Shading
Colour Palette
Entities
Scripted Sectors
Y Shearing
Raycasting
Portal Culling

This runs at about 500 FPS at 1920x1080 on a Ryzen 5 5500 with an uncapped frame rate. It is capped to 100 FPS.
Edit settings.ini if you want to change the resolution.
